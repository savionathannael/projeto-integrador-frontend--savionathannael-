# projeto-integrador-frontend--savionathannael-
Loja Virtual de produtos 3D
Este projeto tem como tema uma loja virtual de produtos com visualização em 3D.
O objetivo é apresentar um catálogo de produtos onde o usuário pode girar,
ampliar e visualizar os itens em modelos tridimensionais antes da compra,
oferecendo uma experiência de compra mais imersiva do que fotos estáticas.



Avaliação: A estrutura do projeto está bem feita e legível, possuindo comentários que deixam o código fácil de entender, o tema proposto é bem interessante e o projeto em si capta muito bem o tema e o visual do site também 
é muito bonito, além disso o projeto atende bem o que foi pedido ao decorrer das aulas. No mais, é um projeto bem feito e bem estruturado além de ser bem completo.
